# About SafeCity

**SafeCity** is an advanced operational intelligence and decision-support platform designed for the **Chicago Police Department (CPD)**. The platform is engineered to consolidate, visualize, and analyze criminal records, patrol logistics, and officer assignments to improve public safety and resource allocation.

---

## 🎯 Core Objectives

1. **Data-Driven Policing:** Transition CPD operations from legacy, passive record-keeping to proactive, data-driven tactical responses.
2. **Resource Optimization:** Maximize patrol fleet efficiency and coordinate shift planning based on real-time crime hotspot analysis.
3. **Investigative Continuity:** Provide detectives with digital case management tools to link suspects, evidence, witnesses, and progress logs.
4. **Enhanced Auditing & Security:** Enforce strict access control, user authentication, and data integrity audits to comply with judicial standards.

---

## 🧩 Functional Modules

### 1. Operations Dashboard
A central command interface displaying real-time Key Performance Indicators (KPIs) calculated over **200,000+ historical crime records**:
* **Crime Heatmap:** Dynamic visualization of crime density patterns across Chicago using CartoDB Dark Matter tiles.
* **Hotspot Markers:** Highlights the top 5 highest-risk geographic coordinates.
* **Crime Distribution Chart:** Interactive bar charts showing crime volume aggregated by police district.
* **Activity Feed:** Live chronological feed of the most recent incidents.

### 2. Field & Geographic Intelligence (Tactical Map)
A full-screen interactive GIS interface for geospatial query execution:
* Filter crimes dynamically by street name, block, or district.
* Analyze crime hotspots based on custom date ranges and primary classification types.

### 3. Departmental Logistics
A comprehensive Fleet and Officer Patrol CRUD module:
* **Patrol scheduling:** Link specific patrol officers to active patrol vehicles and beats.
* **Fleet Management:** Monitor squad car availability (Active, In Maintenance, Damaged).
* **Gear Auditing:** Trace serial numbers and assignments for radio, taser, body cam, and laptop equipment.

### 4. Criminal Intelligence Hub
A centralized database mapping gang structures, suspect profiles, and testimonies:
* **Gang Catalog:** Tracks operational zones and threat levels for Chicago street gangs (e.g., Latin Kings, Gangster Disciples, Vice Lords).
* **Suspect Files:** Document aliases, prior records, and interview statements.
* **Evidence Directory:** Roster of seized weapons, drugs, and other physical evidence linked to case files.

### 5. Special Investigations (My Cases)
A specialized board for detectives to oversee major cases:
* Manage assigned cases, document investigative progress, link witnesses, and coordinate final prosecution files.

## 🏗️ Architectural Overview

SafeCity utilizes a modern, decoupled three-tier analytical architecture:

```
+---------------------------------------+
|          Angular Presentation         |  <-- Interactive Tactic UI
|    (SPA / Standalone Components)      |
+---------------------------------------+
                   |  (REST APIs)
                   v
+---------------------------------------+
|      Django REST API Middleware       |  <-- Business Logic & Security
+---------------------------------------+
                   |  (Python Client)
                   v
+---------------------------------------+
|       ClickHouse Analytical DB        |  <-- High-Performance Columnar Store
|   (MergeTree Columnar Databases)      |
+---------------------------------------+
```

* **Data Compression & Loading (ETL):** Powered by **Apache Airflow**, which runs weekly automated ETL pipelines to extract records from PocketBase, convert them to pyarrow-compressed Parquet files, and load them into ClickHouse Cloud.
* **Authentication:** Handled via custom signed **JSON Web Tokens (JWT)** generated by the Django authentication backend.
